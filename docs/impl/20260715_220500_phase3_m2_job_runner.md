## 交付

|----|------|

### Job 类型

| type | 含义 |
|------|------|
| `dense_batch` | 多 batch DGEMM；auto 或 `force_ve` + shared pin |
| `sparse_dense` | stencil SpMV → dense |
| `dataprep` | 清洗 → 标准化 → 投影 |

### 用法

```bash
uct-run --list
uct-run jobs/dense_batch.json
uct-run jobs/dataprep.json --host-only
uct-run dense_batch_ve_win.json --shutdown

python scripts/timeline_report.py artifacts/examples/e2_sparse_then_dense/timeline.jsonl
```

```python
from uni_cute_tensor import run_job

```

## Host 不占优场景（W3.3）

模板 **`jobs/dense_batch_ve_win.json`**（256³ × 32 batch，shared AVEO pin）：

| 路径 | thr（约） |
|------|-----------|
| shared pin（常驻） | **~420 batches/s** |
| cold oneshot `ve_exec` | **~6 batches/s** |
| Host OpenBLAS | ~**730** batches/s（本机仍常最快） |

**结论（诚实）**: 相对 **冷 VE oneshot**，常驻 pin **~70×** thr — 这是加速器路径必须常驻的证据。相对 Host OpenBLAS 中规模 thr 仍可能落后；决策层（M1）与 break-even 表说明何时不必上 VE。
