> 计划: `docs/plan/20260716_011100_use_case_service_and_paper.md`

## 交付

### S1 服务

| 项 | 路径 |
|----|------|
| 服务文档 | `docs/SERVICE.md` |
| 模板 | `jobs/service_dense_stream.json`, `service_sparse_dense.json` |
| 连续投递 | `scripts/submit_loop.py` |
| `phi` 字段 | 全 job 类型统一；fallback Host |

### S2 论文

| 项 | 路径 |
|----|------|
| 扫参 | `scripts/paper_sweep.py` → `artifacts/paper/<exp_id>/` |
| 输出 | `manifest.json`, `metrics.jsonl`, `summary.md` |

### S3 Phi 按需

| 项 | 路径 |
|----|------|
| 异构模板 | `jobs/phi_prep_ve_gemm.json` (`type=phi_prep_ve_gemm`) |
| 语义 | `phi:true` 默认尝试 Phi；无设备/失败 → Host note |

---

## 指标（无功耗）

- `throughput_batches_per_sec`
- `speedup_vs_oneshot` / `speedup_vs_host_dgemm`
- `prep_sec` / `prep_note`
- `max_abs_err`

---

## 复现

```bash
# 服务
uct-serve --host-only &
python scripts/submit_loop.py --job jobs/dense_batch.json --n 5 --host-only

# 论文 quick
python scripts/paper_sweep.py --quick --host-only --exp-id smoke

# Phi 模板（无 mic 则 host fallback）
uct-run jobs/phi_prep_ve_gemm.json --host-only
```
