## 可写 claim（论文友好）

1. **常驻 pin thr ≫ cold oneshot**：256³×16 pin ~**83×** oneshot；512³×16 ~**15×**；方向稳定。  
2. **中尺寸单次 / 少 batch：Host OpenBLAS 常赢 latency**（尤其 256–512，`vs_host` 常 ≤1）。  
3. **服务价值在 residency + 多 job session 复用**，不是「任何一次 GEMM 都压过 Host」。  
4. **正确性**：本基线全部 `status=pass`（err 阈值内）。  
5. **Phi**：本表默认关；需要 prep 时用 `--phi-try` 或 job `"phi": true`（失败 Host fallback）。

## 工程注记

- oneshot 使用 `ve_exec` 冷路径；与共享 AVEO 不能同节点并发 → job_runner 在 oneshot 前 `shutdown_sessions()`。  
- oneshot 后端每个 N 只跑一次（不按 batches 重复）。  
- ve_pin 的 `compare_oneshot` 仅在 `batches≥8` 且 `N≤512` 时开启（控时间）。  
- 图：`fig_thr_vs_batches.png`, `fig_vs_oneshot.png`。
