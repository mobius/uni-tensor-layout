# 实现记录 — Phi MKL DGEMM + Host AVX-512

> 文档时间: 2026-07-15 01:48:27

---

## 交付

| 组件 | 路径 | 说明 |
|------|------|------|
| Phi MKL 内核 | `kernels/phi/dgemm_mkl.c` | 原生 KNC `cblas_dgemm` |
| Phi 后端 | `backends/phi_dgemm.py` | `backend=auto\|mkl\|imci` |
| Host AVX-512 | `kernels/host/dgemm_avx512.c` + `host_avx512_dgemm()` | OpenMP + FMA ctypes |
| 基准 | `scripts/bench_phi_dgemm.py`, `bench_host_dgemm.py` |

`auto`：ICC 可用时优先 MKL，失败回退 IMCI。

## Phi 实测（244 threads，正确性 vs numpy）

| N | MKL GFLOPS | IMCI GFLOPS |
|---|------------|-------------|
| 256 | 103 | 78 |
| 512 | **385** | 111 |
| 1024 | **597** | 92 |
| 1536 | **748** | 95 |
| 2048 | **694** | 101 |

相对手写 IMCI：大矩阵约 **7×**。  
相对理论峰值 1208 GFLOPS：MKL 约 **62%** @ 1536。

## Host 实测（OMP 48）

| N | numpy (OpenBLAS 类) | AVX-512 手写 |
|---|---------------------|--------------|
| 256 | 11 | **205** |
| 512 | 37 | **176** |
| 1024 | **228** | 154 |
| 2048 | **390** | 145 |

手写 AVX-512 在小/中规模更快；大矩阵 vendor BLAS 更强（预期）。
