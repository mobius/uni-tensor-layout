### multi-VE layout NLC DGEMM

| 规模 (M×K×N) | 分片 | 单卡 kernel GFLOPS | assemble max_abs_err | 结果 |
|--------------|------|--------------------|----------------------|------|
| 192×160×128 | 64+64+64 | ~65 | **0** | pass |
| 512×512×512 | 171+171+170 | ~900–924 | **2.3e-13** | pass |
| 1536×1024×1024 | 512×3 | ~1390–1405 | **4.0e-13** | pass |

说明:

- kernel GFLOPS 为卡内 `cblas_dgemm` 计时（不含 Host↔文件 staging）。  
- wall / effective GFLOPS 含文件 I/O 与进程启动，规模小时被 I/O 主导（符合 PCIe/FS 瓶颈认知）。  
- 正确性相对 Host `numpy` 参考。
