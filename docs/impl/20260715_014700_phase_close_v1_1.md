## 3. 实测收益（本机 class，固化认知）

| 点 | 结果 |
|----|------|
| AVEO pin vs session @512 multi-batch | ~**1.25×** thr |
| Auto place vs 固定 3-VE mid-size | ~**2×** wall 改善 |
| E5 resident pin vs cold oneshot | ~**4.7×** jobs/s（示例尺寸） |
| Host OpenBLAS mid-size | 常仍赢单次卸载（可解释：DRAM vs PCIe） |
| 正确性 | unit/device/examples smoke 绿；e2e err ~0–1e-12 |

**阶段结论**: 价值在 **系统化（放置、数据面、观测、案例）**，不在继续抠 kernel GFLOPS。
