# Phase 4 M2 — uct-serve Unix socket daemon

> 文档时间: 2026-07-15 23:05:00  
> 版本: **1.5.0**

---

## 交付

| 项 | 路径 |
|----|------|
| 协议 | `runtime/serve_protocol.py`（一行 JSON 一请求） |
| 服务 | `runtime/serve.py` · **`uct-serve`** |
| 客户端 | `uct-run --socket [/tmp/uct-serve.sock]` |
| 健康 | `session_health()` · `--health` / `--ping` |

---

## 用法

```bash
# 终端 1：长驻（仅 Unix socket，权限 0600）
uct-serve --socket /tmp/uct-serve.sock --host-only
# 有卡预热 pin：
# uct-serve --preload 512 --ve-node 1

# 终端 2：投递 job（session 跨 job 复用）
uct-run --socket jobs/dense_batch.json --host-only
uct-run --socket --ping
uct-run --socket --health
uct-run --socket --shutdown
```

协议（每连接一个请求）:

```json
{"op":"run","id":"j1","job":{"type":"dense_batch","m":64,"batches":2},"host_only":true}
{"op":"ping"}
{"op":"health"}
{"op":"shutdown"}
```

---

## 与 uct-run 本地模式差异

| | 本地 `uct-run` | `uct-run --socket` + `uct-serve` |
|--|----------------|----------------------------------|
| 进程 | 每 job 起进程 | serve 常驻 |
| VE session | 进程内多 batch 复用 | **跨 job** 复用 |
| 并发 | 多进程并行 | serve 内 job **串行锁**（保护 AVEO） |

---

## 安全

- 只绑 **AF_UNIX**，不监听 TCP  
- socket 文件 `chmod 600`  
- 不默认开公网 HTTP
