## 2. 安装（一页纸）

```bash
# isolated
uv venv --python 3.13 env/.venv
source env/.venv/bin/activate
uv pip install -e ".[dev]"          # or: .[test] / .[all]
# optional markers (docs only; toolchains on machine):
#   uv pip install -e ".[aveo,phi]"

bash scripts/check_hw.sh            # no serials
bash scripts/ci_l0.sh               # same as GitHub L0
pytest -q -m device                 # optional on this HW class
```

Optional env:

| Env | Purpose |
|-----|---------|
| `UNI_ROOT` | uni-framework checkout |
| `INTEL_LICENSE_FILE` | ICC for Phi (never commit license) |
| `VE_LD_LIBRARY_PATH` / `LD_LIBRARY_PATH` | NLC + libveo |
