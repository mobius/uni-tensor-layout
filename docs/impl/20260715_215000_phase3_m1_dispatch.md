## 本机结论（摘要）

- **单 batch / 中规模**: 实测与 recommend 多指向 **host**（OpenBLAS 强）。  
- **多 batch + pin**: 小 N（如 256×16）pin 可胜；大 N 仍常 host。  
- **oneshot**: 估计与实测均差于 pin/host — 多 job 应常驻。  
- 校准 rel_error 仍偏高（模型粗）；**推荐方向**（host vs multi-batch VE）可用，不作精确 SLA。

详见同目录最新 `*_breakeven.md`。
