## 2. 稳定 API 表

### 2.1 Atoms / 布局代数

| 符号 | 说明 |
|------|------|
| `HOST_AVX512_8x8x8_F64` | Host AVX-512 atom 描述 |
| `PHI_KNC_8x8x8_F64` | Phi KNC atom |
| `VE_NLC_DGEMM_64x64x64_F64` | VE NLC tile atom |
| `list_atoms()` | 注册 atom 名列表 |

### 2.2 Placement

| 符号 | 说明 |
|------|------|
| `PlacementPlan` / `Shard` | 多设备放置；`to_json` / `from_json` / `write_json` / `load_json` |
| `partition_matrix_rows/cols/k` | 固定策略分片 |
| `partition_to_devices` | 按 kind 选 atom 的行切 |
| `choose_best_placement(m,n,k,devices,...)` | 自动策略 + 设备子集（可选 PowerCap） |
| `estimate_gemm_placement(...)` | 单策略代价估计 |
| `execute_plan(A, B, plan)` | plan → GEMM 执行 |
| `execute_auto(A, B, devices)` | choose + execute |

### 2.3 Host GEMM

| 符号 | 说明 |
|------|------|
| `host_dgemm(A, B, backend=...)` | `auto` \| `openblas` \| `avx512` \| `numpy` \| `blocked` |
| `host_dgemm_reference` | numpy 正确性 oracle |
| `host_sharded_dgemm(A, B, plan)` | 按 plan 的 Host 分片模拟 |

### 2.4 Power / Runtime

| 符号 | 说明 |
|------|------|
| `PowerCap` | 功耗预算；`can_launch` / `reserve` / `release` / `guard` |
| `create_dataplane(backend)` | `host` \| `file` \| `worker` \| `aveo` \| `aveo_pinned` |
| `GemmRequest` / `GemmResult` | DataPlane I/O |
| `Timeline` / `timeline_scope` | JSONL 阶段日志 |

### 2.5 扩展 API（稳定但经子模块导入）

## 3. 语义约定

| 项 | 约定 |
|----|------|
| 矩阵布局 | Host 默认 **row-major contiguous** `float64` |
| GEMM | \(C = A @ B\)，A is \(M\times K\)，B is \(K\times N\) |
| 设备名 | `host`、`phi0`、`ve1`…`veN`（与 `ve_exec -N` 一致） |
| 正确性 | 相对 numpy 参考，`max_abs_err < 1e-8`（FP64）为 pass |
| PowerCap | 默认 1600W×0.9；有 `UNI_ROOT` 时优先 uni 实现 |
| PlacementPlan.version | `"0.2"` JSON schema（字段可增，不删） |

---

## 4. 弃用（Deprecated）

| 项 | 状态 | 替代 |
|----|------|------|
| `host_blocked_dgemm` / `backend="blocked"` | **教学用**，非性能路径 | `host_dgemm(..., backend="openblas"\|"auto")` |
| pure-Python tile GEMM 作为 benchmark | 不作为性能基线 | OpenBLAS / AVX-512 / NLC / MKL |
| 无 pin 的 AVEO oneshot 多 batch | 可用但慢 | `aveo_pinned` 或 session pool |
| 固定 3-VE 行切不经 cost model | 可用 | `choose_best_placement` |

弃用 API **至少保留整个 1.x**；移除仅在 2.0 并在 CHANGELOG 说明。
